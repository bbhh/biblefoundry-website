# BibleFoundry

The official BibleFoundry website, built with Hugo.

Run `hugo server` for a local preview. Run `hugo` to rebuild the static site in `docs/`.

To add an app, create a Markdown page in `content/apps/` using
`five-psalms.md` as an example. The home and Apps pages use the title,
description, icon, and weight to render the catalog. Add store links and
release notes on the same page.
